# Contributing

This project is being developed incrementally with AI-assisted planning and scaffolding. Changes require human review and reproducible tests; commit history records actual milestones, not a simulated development timeline.

Read the spec, propose the smallest useful change, add tests for its failure cases, run the verification suite and record evidence. Explain ownership, reasoning and limitations honestly when demonstrating the project.

Never commit secrets, actual customer records, generated build outputs or benchmark claims without artifacts. Keep fixtures synthetic and reproducible.
