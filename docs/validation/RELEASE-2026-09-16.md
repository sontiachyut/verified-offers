## CI and handoff

Every push runs the [acceptance workflow](https://github.com/sontiachyut/verified-offers/actions/workflows/ci.yml).
The Java job repeats the complete suite, HTTP demo, real-dependency React
walkthrough and hardened image smoke. The console job repeats client checks.
Reports/evaluation artifacts are retained for 14 days under the exact commit SHA.
Superseded runs are cancelled; they are not successful evidence. Check the exact
handoff revision's conclusion before release, not merely a previous green badge.
